# 提示词设置

录课栏计时器左侧新增“提示词设置”按钮。可在未录课、录课中以及专注阅读状态打开。

## 可编辑项目

| 项目 | 实际用途 |
| --- | --- |
| 补听重点 | 主题、简短重点、当前进度；继续使用原有引用校验 |
| 提问 | 所选时段的约500字连贯回答，不生成逐句引用 |
| 分层补听 | 主线及可展开重点，区分课堂复述和AI辅助解释，不生成逐句引用 |
| 云端摘要连接测试 | 设置页短调用发送的user消息，输出预算16 tokens |
| 本地摘要检测·规则 | 本地可用性测试system消息，输出预算32 tokens，需回答包含OK |
| 本地摘要检测·请求 | 本地可用性测试user消息 |
| 语音识别·课程术语 | 与服务设置的课程术语共用，作为云端ASR的corpus.text发送，可留空 |

选择左侧项目，右侧即可查看与修改完整原文。“本项恢复默认”先恢复编辑框内容，点击“保存提示词”才生效。未保存直接关闭会提醒；保存失败保留草稿。

## 生效与限制

生成提示词从下一次请求生效，正在生成的请求保持原设置。课程术语从下一次建立识别连接生效；本地ASR不使用此术语字段。编辑与保存本身不会调用API或切换处理模式。

请保留内置提示词中的JSON字段与结构。可改语言、详略、讲解风格和关注点；自行删除JSON约定、要求输出程序不支持的格式，仍可能导致结果校验失败。提示词的格式约定不等于事实核验。

request中的时间范围、问题以及transcript中的真实转写由程序动态生成，不作为固定模板编辑。密钥、服务地址和模型名仍在服务设置中管理。仓库中保留的上游Meetily会议纪要与翻译模板未用于当前课堂流程，因此不列为生效提示词。

## 保存位置

自定义生成与检测提示词保存在 `G:\MeetingAssistant\data\settings.json` 的 `prompt_overrides` 字段；术语仍使用 `vocabulary` 字段。默认内容不会重复保存为覆盖值。每次保存前，原设置备份到 `data\settings.before-prompts.json`；临时文件完整写入后替换正式设置。

API密钥仍由Windows凭据存储管理。多窗口同时编辑时，后保存的窗口会收到冲突提示，需重新打开以读取最新设置。

内置默认提示词原文：[API提示词清单.md](API提示词清单.md)。该文档不导出用户当前的自定义提示词。
