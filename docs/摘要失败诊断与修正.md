# 摘要连接失败或超时：诊断与修正（2026-10-20）

## 本次判断

截图中的“用中文总结”是有效输入。实际配置是云端 qwen-plus，地址为阿里百炼 compatible-mode/v1。原版提问模式总超时只有45秒，需接收完整响应后才显示；五分钟英文转写再生成约500字中文回答，可能超过这个时间。

旧代码把连接失败和超时统一显示成“摘要连接失败或超时”，没有保存失败类型。因此无法证明这次一定是超时，也不能据此断定密钥失效。检查时未携带密钥的端点请求能在约0.38秒获得HTTP回应，仅能证明当时网络可达，不能证明鉴权、额度或模型调用正常。

## 修改

- 建立连接最多10秒；补听重点、提问、分层补听总等待上限分别60、120、180秒。
- 分别提示连接失败、连接超时、完整响应超时、HTTP鉴权/权限/额度/服务错误、无法解析响应。
- 接收响应正文超时也显示超时，不再误报为JSON错误。
- 失败元数据保存在 data/diagnostics/summary-transport-<任务ID>.json，记录模式、模型、服务主机、耗时、输入字节数、片段数、状态码及安全请求ID。此文件不含密钥、问题、课堂正文或模型回复。
- 不自动重试，不自动切换本地；录音和转写继续。原补听提示词及输出预算不变。

## 验证与使用

7项本地HTTP模拟测试通过：正常响应、响应头延迟、正文延迟、401/403/429/503、非JSON、连接拒绝、模式时间预算。没有使用真实课堂内容或调用收费模型。

当前课堂正在录制，保持运行中的旧程序不变。更新需在结束并保存课程、完全退出程序后生效；不能把源代码修正等同于正在运行的程序已经更新。若尚未更新，可先选择1至3分钟重试，避免连续重复点击；在设置中测试摘要连接能初步检查鉴权与模型配置，但短测试通过不保证长回答在45秒内完成。
