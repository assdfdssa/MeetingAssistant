# 提问与分层补听取消引用

日期：2026-10-28。

提问与分层补听不再要求模型生成句子引用、编号或来源列表。输入仅包含所选时间范围内的转写正文及时间戳，移除模型输入里的片段编号。提示词继续要求忠实于课堂内容、承认信息缺失，并区分课堂复述与 AI 补充说明。

为兼容历史卡片，输出 JSON 的 segment_ids 字段保留为空数组；程序清空模型误填的引用，不再执行这两个模式的引用还原和 8 条上限拦截。继续校验内容非空、长度、重点数量及模式必需字段。所选范围的原始转写仍随卡片保存，新卡片不显示逐句“查看依据原文”按钮，旧卡片已有引用仍可使用。

按此前要求，“补听重点”的提示词和原引用校验保持不变。

提示词完整原文见 API提示词清单.md，源码为 meetily/frontend/src-tauri/src/classcatch/prompts.rs。

验证：核心测试 16 项通过；前端生产构建（含类型检查）通过。取消引用减少模型格式负担，但不等于自动核实摘要事实；用户仍可对照同时间范围的课堂实录。

桌面程序构建成功：build/native/debug/meetily-no-citations.exe。启动脚本校验就绪标记中的文件长度和 SHA256 后将其纳入候选，默认选择最新完成版本。没有自动启动程序，也未发送真实课堂数据进行云端测试。
