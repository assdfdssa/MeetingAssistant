# 提问、分层补听与历史记录

## 三个入口

| 模式 | 如何使用 | 输出 |
| --- | --- | --- |
| 补听重点 | 选择最近1/3/5/10分钟或自定义分钟 | 保留原提示词：主题、最多3点、当前进度，以及检出的任务 |
| 提问 | 写问题或总结要求，再选最近范围或指定课堂起止时间；也可留空 | 目标约500字的一段连贯回答，片段不足时不凑字数，附原文入口 |
| 分层补听 | 选时间后生成，先读主线，再展开重点 | 第一层快速补听；第二层显示课堂复述、AI白话解释、可选举例和关系梳理 |

提问示例：“请用白话解释老师这段论证的前提和结论”“总结这段实验操作，解释每一步的作用”“这里的 prior 和 posterior 有什么区别？”

指定时间是课堂开始后的时间，不是电脑时钟。支持 `05:00`（第5分钟）和 `01:05:00`（第1小时第5分钟）。起止跨度10秒至60分钟，结束时间不能超出当前课时。与窗口重叠的转写片段会完整传入，边缘可能略超出所选秒数。仅已确认转写参与请求。

## 为阅读腾出空间

操作区顶部的“收起/调整”按钮可折叠模式、范围和提问框。收起后仍显示当前模式、范围、记录数量和生成按钮。请求成功提交后自动收起；草稿保留，重新展开即可修改。

“记录 N”打开本节课的全部已保存补听记录，可以按标题、问题、模式或结束时间搜索。选择记录后关闭菜单并切换正文，不删除、不重排其他记录。与旧版只展示最近4条的界面不同，这里展示本课全部数据库记录。切换课程后显示对应课程的记录。

## 展开解释与继续提问

分层内容在首次请求中一并生成，展开不额外调用模型。界面将有依据的“课堂内容复述”和“AI辅助理解”分开显示；补充解释、AI举例及关系梳理不代表老师原话。点击原文入口可核对课堂转写。

“就这个重点继续提问”把重点和原时间范围填入提问草稿。用户点击“生成回答”后才发送新请求；不会自动调用或计费。

全局快捷键仍按最近范围生成，不携带某个窗口尚未提交的问题和指定时间草稿。使用指定区间或自写问题，请点击窗口内生成按钮。旧版保存的 tasks/explain 卡片仍可打开；旧设置中的这两种模式分别映射为提问/分层补听，不重写旧卡片。

## 提示词和验证边界

全部实际提示词原文见 [API提示词清单](API提示词清单.md)。编辑Markdown不会改变程序，需改源码并重新编译。

补听重点沿用1600输出token预算；提问2200，分层补听3600。云端请求总超时：补听重点60秒、提问120秒、分层补听180秒；建立连接超时10秒；模型生成期间录音和转写继续。更详细的输出可能增加耗时和费用。约500字是生成目标，不能保证每次精确字数。

本地应急模型上下文有限，分层模式超过约2000字符的输入将提示缩小范围；其他本地模式维持原限制。本次没有更换语音识别模型。

验证使用模拟课堂与隔离SQLite数据：检查指定时间请求、单段回答、分层展开、依据引用、15条历史记录及搜索、不同尺寸布局和旧卡片兼容。检查结果不等于真实云端模型质量或长课录制验收。
