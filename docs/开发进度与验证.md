## 当前边界

1. PPT/PDF 检索与翻译专用界面暂未实现，仍属下一阶段。英文课堂可保留英文转写并生成中文补听。
2. 网络断开会重连；实时队列超载可能产生转写缺口并提示。尚无离线录音自动补转写，不应理解为断网后字幕必然完整。
3. 任务引用校验能拦截不存在的片段或日期，但不能证明模型对否定、取消、延期的理解一定正确，需要核对原话。
4. 目前任务勾选只影响当前窗口，尚未持久保存；原始任务和补听卡片会保存。
5. 本项目运行时使用用户指定的 `G:\MeetingAssistant\data`。同学没有 G 盘时，安装版回退到 `%LOCALAPPDATA%\MeetingAssistant\data`；文件访问范围随实际数据目录设置，不要求同学创建 G 盘。
6. 系统声音为可选项，需要 Windows 实机验证；云端连接成功不代表已测量真实课堂识别准确率。
7. 上游录音每约 30 秒创建音频检查点，异常断电时尚未形成检查点的尾部可能丢失。正常结束会先排空保存队列；异常退出后的检查点自动恢复界面尚未完成。

## 构建环境与已遇到的问题

本机 G 盘不支持常规软链接/硬链接及部分压缩包的早期文件时间戳。依赖安装使用复制模式；Cargo 包保留原始归档并校验锁文件 SHA256，解压时不恢复不受支持的时间戳。工具位于 `tools/`，不修改上游依赖内容。

前端静态导出不需要 Node 服务端追踪，已关闭文件追踪与 Webpack 软链接解析；生产构建使用独立 `.next-production`，避免开发预览锁定缓存文件。Windows C++ 编译工具及 Rust 工具链保存在 `tools/`。

交付程序可独立读取已导出页面，无需启动开发服务器，输出目录为 `build/native/`。安装包副本在 `dist/课堂补听助手-0.4.1-Windows-x64-安装程序.exe`。原生依赖安装中已补齐官方 Ninja、UTF-8 编译选项和 Windows libclang 绑定生成；上游预生成的 Linux ABI 绑定没有用于交付。最终编译见 `logs/delivery-final-build.log`，最终独立启动测试见 `logs/native-standalone-test.log` 与 `logs/native-smoke.json`。其他 `native-resume*` 等日志保留用于诊断，不能将早期失败当作当前结果。

上游自动更新插件已移除，避免配置缺失导致启动失败，以及误用上游更新渠道。桌面库只生成当前 Windows 可执行程序需要的中间库。安装工具缓存在项目构建目录。

界面预览现在用 `tools/preview-server.cjs` 读取已完成的静态导出，不依赖开发热更新。最新主界面和快捷弹窗测试都针对这个静态版本执行。

百炼千问摘要请求明确使用非思考模式以生成简短 JSON 卡片；该平台专用参数不会传给 DeepSeek。配置自定义模型时应选择支持非思考 JSON 输出的模型。

## 第一轮实机验收

1. 在设置中填写北京地域百炼密钥，并分别测试语音和摘要连接。同一密钥如有两类模型权限，可在两栏分别填写。
2. 选外置麦克风，录制 2 分钟中文、英文与混合口述，确认字幕及本机音频。
3. 录音中触发快捷键与三种模式，确认字幕持续、没有第二路录音启动。
4. 暂停一分钟再继续，回放前后引用，确认时间映射准确。
5. 临时断网，确认告警、恢复、原始音频仍保存，并明确识别缺口。
6. 连录两节课，实际测量：摘要是否能在 30 秒内读完并接上课堂，任务是否含准确原话，磁盘和内存是否稳定。

## 2026-10-19 固定工作区与独立滚动
