# 专注阅读

在“课堂实录”和“一键接上课堂”的标题栏，点击右侧的放大图标即可使用。

| 操作 | 布局 |
| --- | --- |
| 仅打开课堂实录的放大按钮 | 实录约占七成，摘要约占三成 |
| 仅打开一键接上课堂的放大按钮 | 摘要约占七成，实录约占三成 |
| 同时打开两侧放大按钮 | 两栏各占一半 |
| 再次关闭两个按钮，或点击顶部“退出专注” | 恢复普通布局 |

专注阅读会收起课程侧栏、大标题和页脚，将顶部录音控制压成紧凑工具栏。计时、暂停、结束保存和设置入口仍可使用。正文文字略微放大，右侧操作区压缩间距，以留出更多摘要阅读空间。

转写和摘要继续在各自区域内部滚动。切换布局不会重新创建面板、清空提问、重新开始录音或发起摘要请求。阅读历史转写时，新增内容不会强制跳到末尾，仍可点击“回到最新”。

为了让较窄窗口中的按钮仍能完整操作，窗口宽度为 701–900 像素时，专注布局保持左右均分；更窄的窗口使用上下排列。这里的像素是 Windows 缩放后的界面尺寸。快捷补听的小窗口保持原有单栏布局。

布局选择仅对当前窗口本次打开有效；重新启动后恢复普通布局。不会修改模型、密钥或录音设置。

## 验证

交互验证脚本：`tests/ui-focus.cjs`。

在 1280×720、1600×960、820×620 三种窗口尺寸下，检查单侧放大、双侧均分、退出恢复、键盘操作、输入保留、独立滚动和录音控制可见性。测试使用模拟课堂数据，不会开启麦克风或调用云端 API。

验证结果保存在 `logs/ui-focus-test.json`，界面截图保存在 `build/专注阅读-*.png`。
