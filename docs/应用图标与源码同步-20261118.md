# 应用图标与源码同步

新图标使用森林绿渐变圆角底、米白色耳机、打开的书页及暖金色星点，表达“听课、理解、重新跟上”。图形由本项目原创SVG绘制，不使用生成式位图或上游Meetily的紫色品牌标志。

矢量源文件：`meetily/frontend/src-tauri/icons/classcatch.svg`。界面副本：`meetily/frontend/public/classcatch-mark.svg`。`tools/Build-Brand-Icons.py`调用项目内Tauri图标工具并生成ICO、ICNS及PNG尺寸资源，需要Pillow；可通过已配置的开发Python环境运行。

Windows ICO包含16、24、32、48、64及256像素图层。Tauri配置指向`icons/icon.ico`、`icons/icon.icns`和`icons/icon.png`；托盘继续使用默认窗口图标。浏览器favicon与课堂左上角标志共用新图形。

源码同步采用`tools/Prepare-GitHub-Snapshot.py`生成白名单快照，与远程main逐文件比较后更新；保留上游许可、子模块关系及现有远程历史。不上传data、data-backups、logs、本地工具链、模型、编译缓存、安装包或真实课堂资料。

同批同步包含提示词设置及其备份、已确认转写时间窗口、摘要生成预算与截断诊断、取消新学习模式逐句引用、Windows启动器兼容性修正。可编辑提示词的规则及限制见[提示词设置使用说明](提示词设置使用说明.md)。
