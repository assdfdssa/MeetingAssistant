## 从这里开始

- `预览界面.cmd`：查看界面和模拟课堂，浏览器预览不录音、不调用 API。
- `启动桌面版.cmd`：启动已编译的桌面程序；如果尚未编译完成，会明确提示。
- `build/native/debug/bundle/nsis/`：Windows 安装包。安装包生成后可以给同学使用，不需要复制整套源码与编译工具。
- `dist/`：便于查找的交付文件与校验信息。
- [开发进度与验证](docs/开发进度与验证.md)：查看实际进度、验证结果和待办。
- [完整开发文档](docs/课堂补听助手-开发文档.md)：需求、架构与入门说明。
- [专注阅读](docs/专注阅读使用说明.md)：两侧标题栏的放大按钮，可优先阅读实录、摘要，或让两栏均分窗口。
- [提问与分层补听](docs/提问与分层补听使用说明.md)：指定时间提问、约500字回答、展开重点解释，以及可搜索的完整历史菜单。
- [课程修复](docs/课程修复与检查点恢复.md)：从录音检查点恢复可播放音频，补回转写，并明确标注无法找回的部分。
- [Meetily 实施映射](docs/Meetily实施映射与迁移清单.md)：上游模块与改造方案。

## 配置百炼中国内地服务

桌面版右上角打开设置。实时语音默认模型为 `qwen3-asr-flash-realtime`，摘要默认模型为 `qwen-plus`，摘要地址为 `https://dashscope.aliyuncs.com/compatible-mode/v1`。两栏填写拥有对应权限的百炼北京地域 API Key。不要将密钥放进聊天、源码或截图。

可以先分别测试连接，再录制一小段中文、英文与中英混合的音频。连接测试不等于真实语音准确率测试。也可把摘要服务切换到 DeepSeek；语音识别仍使用百炼。

开始录课后，选择补听范围和模式。`Ctrl+Alt+J` 沿用上次选择立即生成。摘要期间录音和转写继续；课间可暂停，下一节继续。结束时点击“结束并保存”。关闭主窗口后如程序仍在托盘，使用托盘的“结束录音并退出”。

这是开发预览版，已验证桌面启动、设置、设备枚举、界面和核心逻辑。真实 API 调用与 90–120 分钟录课尚待验证；首次配置后请先录两分钟再用于整节课。当前安装包未做代码签名。

## 文件在哪里

| 目录 | 内容 |
| --- | --- |
| `meetily/` | 基于固定版本的上游源码与改造 |
| `data/` | 运行后创建：音频、SQLite 实时事件、转写、补听卡片、非敏感设置 |
| `docs/` | 开发文档、选型资料、进度与验证记录 |
| `build/` | 构建结果、界面预览截图 |
| `tests/` | 界面验证脚本与核心逻辑测试 |
| `logs/` | 构建和验证日志，不包含 API Key |
| `tools/` | 本项目使用的编译工具、包管理器和依赖缓存 |

密钥例外：为避免明文保存在项目里，放在 Windows 凭据管理器中；普通数据仍保存在本项目。

同学安装后若没有本项目 G 盘目录，记录会保存到其 Windows 本地应用数据目录 `%LOCALAPPDATA%\MeetingAssistant\data`。密钥需要在自己的设置页填写，安装包不包含你的密钥或课堂历史。

## 开发入口

前端：`meetily/frontend/src/components/classcatch/Classroom.tsx`。

后端：`meetily/frontend/src-tauri/src/classcatch/`。`core.rs` 管时间窗口与证据校验，`cloud.rs` 管实时识别，`service.rs` 管会话、设置、数据库与摘要。底层录音继续复用 Meetily 的音频模块。

项目工具环境由 `tools/Build-Environment.ps1` 设置。G 盘是 exFAT，依赖安装须使用复制模式；直接使用默认 pnpm 软链接安装可能失败。

## 管理课程记录

在左侧课程右侧点击“…”打开课程设置菜单，再选择所需操作。

- **仅归档**：从常用课程记录中隐藏；录音、实时转写、摘要、任务和原文件全部保留。点击“已归档”查看，也可恢复到课程记录。
- **彻底删除**：勾选永久删除确认后，删除此课程的全部录音、转写、摘要、任务、原始识别事件及录音目录内相关文件。不会进入回收站，无法撤销。

正在录课、暂停或收尾中的课程须先“结束并保存”；补听生成期间也请等待完成后再管理。删除播放中的历史课程会先释放播放器。若文件被其他程序占用导致清理未完成，程序会明确提示并保留清理任务，下次启动继续尝试。
## 2026-10-19 界面交互更新

课堂主界面按窗口可视高度固定布局。转写与摘要不会把整个页面越撑越长：左栏内部滚动查看课堂转写，右栏结果区内部滚动查看摘要及任务。录音操作与摘要模式、时间范围、生成按钮保留在各自固定区域。

实时转写在靠近底部时跟随新内容；向上翻看会暂停跟随，点击“回到最新”恢复。每次生成新摘要，从结果开头阅读。较窄窗口采用上下两栏，在工作区内部滚动；极矮窗口使用内部滚动作为兜底，避免操作被裁掉。

API 实际使用的提示词见 [API提示词清单](docs/API提示词清单.md)；旧会议纪要模板见 [上游附录](docs/API提示词-上游保留模板.md)。Markdown 是源代码快照，修改它不会自动改变程序。
## 2026-10-19 课程设置菜单

左侧每条课程的“…”现在打开课程设置菜单：重命名、在资源管理器中打开、仅归档（归档列表中为恢复课程）、彻底删除。

重命名支持录制中和已保存课程，名称限 1–100 字符；只更改显示名称，不改文件夹名称、不移动音频。打开文件夹会直接打开此课程自己的录音目录；目录缺失或磁盘断开时显示明确提示，不会误跳到其他课程。

菜单支持上下方向键、Home/End、Esc 和点击外部关闭。录制中保留重命名和打开文件夹，归档和删除必须先结束并保存。
